# Tasbih Portfolio v2

Personal portfolio for Tasbih — Management of Islamic Education student and digital project builder.

## Redesign

This version focuses on a clearer narrative, selected work, concise capabilities, journey, and contact. The redesign follows a reusable design-system approach so future UI changes can be made without destabilizing the whole site.

## Development

Built with React, TypeScript, Vite, and Tailwind CSS.
